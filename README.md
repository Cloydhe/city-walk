# 拾光漫步 · 城市旅行打卡手账（名称待定）

## 项目背景

本作品诞生于 **Trae Friends「代码盲盒」挑战活动**：活动以盲盒形式随机抽取两组关键词，创作者选定其中一组作为命题完成开发。

本次抽到的两组关键词：

| 组别 | 关键词 | 结果 |
| --- | --- | --- |
| 第 01 轮 | 天气 × 预演器 × 涂鸦手绘风 | 未选用 |
| 第 02 轮 | **城市散步 × 复盘面板 × 便签墙风** | ✅ 选用 |

选定「城市散步 × 复盘面板 × 便签墙风」后，将三个关键词分别落为产品三大核心功能：**城市推荐**（散步目的地）、**便签墙**（打卡文案与照片的软木墙）、**足迹**（游览记录的复盘面板），整体视觉采用便签墙风格的蜡笔手绘风。

一款蜡笔手绘风的旅行打卡 Web 应用：回答五个心情小问题，让 AI（或内置逻辑）为你选一座城市，沿着规划好的路线逐个打卡，把照片和心情贴上软木便签墙，最后在足迹地图里回看走过的每一条线。

## 功能总览

| 模块 | 说明 |
| --- | --- |
| 引导页 | 首次进入展示引导词与「开始探索」按钮 |
| 城市推荐 | 五层关键词（心情 → 南北气候 → 地貌 → 地方特色 → 玩法）递进选择，大模型/本地规则匹配城市；下方为城市图鉴（纯展示）：已游览城市盖「已打卡」印章，附「看足迹 →」入口 |
| 打卡流程 | 展示推荐城市热门打卡点与顺路路线（大模型可生成路线建议）；每个打卡点提供介绍、注意事项、交通建议、私藏建议（支持 AI 实时生成） |
| 便签墙 | 软木板风格，便签支持文字 + 图片（自动压缩）、6 色蜡笔纸、自由拖动摆放、AI 润色（可撤销）；新便签自动找空位避免覆盖；支持按城市 / 类型（含照片/纯文字）筛选，筛选时便签以 FLIP 动画重排为紧凑网格 |
| 足迹 | 城市视图：手绘城市地图 + 打卡点连线（完成打勾）；全国大盘：按经纬度映射的手绘中国轮廓，红点标记已游览城市 |
| 设置 | 预设 DeepSeek / 通义千问 Qwen / 智谱 GLM 标准接口与旗下模型，选中后只需填 API Key；支持自定义 OpenAI 兼容服务；连接测试；数据清空 |

## 大模型说明

- 「设置」页预设 DeepSeek（`deepseek-chat` 等）、通义千问 Qwen（`qwen-plus` 等）、智谱 GLM（`glm-4-flash` 等）标准接口，选择服务商后只需填写 API Key；也支持自定义任意兼容 OpenAI `/chat/completions` 的服务
- **未配置时所有功能自动使用内置预设内容**，演示不依赖外部 API
- AI 驱动场景：城市推荐理由、城市路线建议、打卡点游玩指南、便签文案润色
- 所有 AI 调用带 15s 超时与异常降级，失败自动回落预设内容

## 技术栈

- 纯静态前端：HTML5 + CSS3 + 原生 JavaScript（无构建、无依赖框架）
- 手绘地图：内联 SVG + feTurbulence 滤镜模拟蜡笔笔触
- 数据存储：localStorage（游览记录 / 便签 / 设置，图片 base64 压缩存储）
- 字体：Google Fonts 中文手写体（Ma Shan Zheng / Zhi Mang Xing），离线自动回退系统字体

## 本地部署

本项目为纯静态前端（无后端、无构建步骤），任选以下一种方式启动本地服务即可：

### 方式一：Python（推荐，macOS/Linux 自带）

```bash
cd city-walk
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
# 停止服务：Ctrl + C
```

### 方式二：Node.js

```bash
cd city-walk
npx serve -l 8080
# 或：npx http-server -p 8080
# 浏览器访问 http://localhost:8080
```

### 方式三：VS Code / Trae 插件

安装 **Live Server** 插件 → 右键 `index.html` → `Open with Live Server`。

### 方式四：直接打开

双击 `index.html` 即可运行。应用无本地资源跨域请求（脚本均为同目录 `<script>` 引入），`file://` 协议下功能完整可用；仅手写字体需联网加载（离线自动回退系统字体）。

> 端口冲突时更换端口号即可，如 `python3 -m http.server 8081`。
> 首次部署体验建议新开浏览器隐私窗口，可从引导页开始完整流程。

## 页面流程

```
引导页 → 城市推荐（图鉴）→ 关键词五选 → 推荐结果（城市+路线）
       → 逐站打卡（指南/写便签）→ 全部完成 → 足迹地图
便签墙：随时查看/拖动/编辑/润色/筛选所有便签，补贴漏写的打卡点
设置：选择服务商（DeepSeek/Qwen/GLM/自定义）→ 填 API Key → 测试连接 / 清空数据
```

## 关键实现说明

- **路由**：hash 路由（`#/recommend`、`#/spot/:index` 等），无需服务端支持
- **图片处理**：上传后经 canvas 压缩至最长边 800px / JPEG 0.75，控制 localStorage 体积
- **便签拖动**：Pointer Events 实现，位置以百分比存储，窗口缩放不偏移
- **日期格式**：前端统一 `YYYY-MM-DD HH:mm`
- **日志**：路由切换、打卡、存储写入、AI 调用等关键节点均输出 `console.log`（前缀 `[CityWalk]`）
